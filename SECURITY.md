# Politique de sécurité / Security policy

## Versions suivies / Supported versions

Seule la dernière version publiée reçoit des correctifs. PeriphHub se met à jour tout seul
(installeur GitHub) ou par le Microsoft Store.

Only the latest release gets fixes. PeriphHub updates itself (GitHub installer) or through the
Microsoft Store.

## Signaler une faille / Reporting a vulnerability

Utilisez le **signalement privé** de GitHub : onglet **Security** du dépôt, puis
**Report a vulnerability**. Ne publiez pas les détails dans un ticket public : si ce bouton manque,
ouvrez un ticket qui demande seulement un moyen de contact privé. Réponse sous quelques jours ; le
correctif est publié dans une nouvelle version, puis la faille est décrite dans ses notes.

Use GitHub **private vulnerability reporting**: **Security** tab of the repository, then
**Report a vulnerability**. Please do not post details in a public issue: if the button is missing,
open an issue that only asks for a private contact. You will get an answer within a few days; the
fix ships in a new release whose notes then describe the issue.

Un **faux positif d'antivirus** n'est pas une faille : voir « En cas de faux positif » dans
[docs/SECURITE.md](docs/SECURITE.md).

An **antivirus false positive** is not a vulnerability: see [docs/SECURITE.md](docs/SECURITE.md)
(« En cas de faux positif »).
